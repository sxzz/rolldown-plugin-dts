# Pull requests

- Before creating or editing a PR, read and follow the [shared PR template](https://github.com/sxzz/.github/blob/main/.github/PULL_REQUEST_TEMPLATE.md) in `sxzz/.github`. The template is inherited from that repository; it is not stored here.
- Preserve the template's HTML comments (including `DO NOT IGNORE THE TEMPLATE!`) and all section headings, and complete the applicable fields. Do not replace the template with a free-form summary. If you cannot retrieve it, ask for its contents before submitting the PR.
- Disclose AI assistance truthfully in the `AI usage` section, including the tool and model used. Never select “No AI was used” when AI assisted with any part of the PR.
- Leave the human-review checkbox for the human contributor. Never check it on their behalf.
- Keep the PR description brief and explain what the change solves.
